# 第一章：设计哲学

---

## 1.1 这个游戏不是什么

这个游戏不是一个解谜游戏。

解谜游戏的核心体验是：玩家面对一个被设计者预设了答案的谜题，通过逻辑推理找到答案，获得"我解开了它"的成就感。

这个游戏的核心体验是：**信息考古**。

玩家进入的是一个已经发生过很多事情的现场。那些事情留下了痕迹——有些痕迹是刻意留下的，有些是无意间留下的，有些是被刻意抹除但没有抹干净的。玩家的工作不是解开一个谜题，而是从这些痕迹里，还原出一个世界和其中的人。

这个区别决定了游戏的每一个设计决策。

## 1.2 参照系：《大学生登山失踪事件》与《诡异广告调查事件》

这两个游戏共享同一套核心设计哲学，值得被精确提炼：

**第一：单一入口，自然蔓延。**
游戏从一个真实可信的现实入口开始，然后像兔子洞一样越挖越深。玩家永远不知道游戏的边界在哪里。

**第二：搜索框是武器，不是菜单。**
玩家主动输入关键词，而不是点击预设按钮。主动搜索产生"我发现了秘密"的感觉，点击按钮只产生"我在走剧情"的感觉。这是沉浸感最关键的来源。

**第三：每条内容都是自洽的真实文本。**
不是"线索A指向B"的游戏提示，而是一条真实的论坛帖、一篇真实的新闻、一封真实的内部邮件。即使不知道它是线索，读起来也是有意思的内容。

**第四：密码永远来自文本本身的逻辑。**
密码不是被"放"在那里等玩家找，而是从文本的内在逻辑里生长出来的。玩家在推导出密码的那一刻，不是在"解谜"，而是在理解这个世界里某个人的思维方式。

**第五：视角切换是核心机制。**
每一层新的访问权限，不只是信息量增加——是玩家对这个世界的理解发生根本性重构。同一件事从不同位置看，变成完全不同的东西。

## 1.3 情感目标

游戏结束后，玩家离开时应该携带的不是"我通关了"的成就感，而是：

- 赵启这个人，因为玩家把他的碎片拼完整，第一次完整地存在于世界上了
- 林晓在凌晨01:07发的那条"预约上了，有点紧张但更多是期待"，会在某个时刻突然浮现
- 那个气味——B1层通风口的气味——玩家关掉标签页之后，也忘不掉

## 1.4 核心设计原则

**原则一：信息的位置本身就是它意义的一部分。**
一条信息住在哪里，以什么形态存在，是这个世界运转逻辑的结果，不是游戏设计者的选择。

**原则二：所有触发必须有机地生长在这个世界里。**
禁止出现任何"空中楼阁式提示"——即玩家无法从已有信息推导出的行动指令。每一个触发条件，都必须能从世界的内在逻辑里得到解释。

**原则三：世界在玩家到来之前已经运转了很久。**
游戏里的每一条内容，不是为了玩家而存在的，而是这个世界本来就存在的东西。玩家只是闯入了一个正在运转的现场。

**原则四：努力的回报是见证，不是胜利。**
玩家付出努力，不是为了换来一个好结局，而是为了真正地看见那些人——看见赵启，看见林晓，看见林医生，看见那些没有名字的编号背后的人。

# 第二章：技术架构

---

## 2.1 整体结构

游戏是一个**单页面应用（SPA）**，使用React + TypeScript + Vite构建，通过HashRouter管理所有路由，绝对禁止真实的浏览器页面刷新。

游戏在浏览器中呈现为一个伪装成真实操作系统的界面，但核心视场不是桌面模拟器，而是：**一个打开了若干窗口的电脑屏幕，玩家通过这些窗口进入不同的信息层。**

## 2.2 核心状态管理

```typescript
interface GameState {
  // 阶段控制
  currentPhase: 0 | 1 | 2 | 3 | 4 | 'ending_a' | 'ending_b' | 'ending_c';

  // 已读取的关键节点
  readNodes: Set<string>;

  // 论坛访问层级
  forumAccess: 'public' | 'member' | 'admin' | 'shadow';

  // OA系统访问状态
  oaLoggedIn: boolean;

  // 七枚碎片收集状态
  collectedRunes: Set<RuneId>; // RuneId: 'RUNE_01' ~ 'RUNE_07'

  // 林晓信号强度（0-7，对应已收集碎片数）
  linXiaoSignalStrength: number;

  // 已发现的关键信息节点
  discoveredFacts: Set<FactId>;

  // 管理员账号是否已破解
  adminUnlocked: boolean;

  // 影子档案是否已访问
  shadowArchiveAccessed: boolean;

  // 赵启邮件是否已显示（结局C前）
  zhaoQiEmailShown: boolean;

  // 结局选择记录
  endingChosen: 'A' | 'B' | 'C' | null;
}
```

## 2.3 防穿越机制

**所有访问权限都需要前置条件验证。**

```typescript
// 示例：OA登录验证
function attemptOALogin(username: string, password: string): LoginResult {
  // 条件一：玩家必须已经在某处发现了OA的存在
  if (!gameState.discoveredFacts.has('oa_url_discovered')) {
    return { success: false, message: '系统连接超时。请检查网络配置。' };
  }
  // 条件二：玩家必须已经知道账号8023的存在
  if (!gameState.discoveredFacts.has('employee_8023_known')) {
    return { success: false, message: '账号不存在或已被禁用。' };
  }
  // 条件三：验证凭据
  if (username === '8023' && password === 'fswltz') {
    return { success: true };
  }
  return { success: false, message: '用户名或密码错误。' };
}
```

**同理，管理员账号、影子档案路径、终局输入框，全部有前置条件锁。**

跳过前置条件直接输入正确答案的玩家，会看到真实感强的系统错误，而不是"密码错误"的游戏提示。

## 2.4 视觉渐变系统：林晓的信号强度

`linXiaoSignalStrength`从0到7，随碎片收集数量增加。

| 强度值 | 表现 |
|--------|------|
| 0 | 官网完全正常，无任何异常 |
| 1 | 某些评价文字的字体间距偶尔出现0.1px的偏移，持续0.05秒 |
| 2 | 第17条评价下方的孤悬回复，鼠标悬停时文字轻微抖动 |
| 3 | 官网某段落背景色在极短时间内出现血色残影，0.1秒后消失 |
| 4 | 官网标题文字偶尔有单个字符在0.2秒内变形为"救"然后复原 |
| 5 | 官网某处段落整行文字在0.3秒内变形为"我还在" |
| 6 | 页面加载完成瞬间，在正常内容出现前，有0.4秒的"救我"全屏覆盖，然后正常内容出现 |
| 7 | 进入终局选择界面前，官网完整呈现一次"我知道你在找我"然后页面崩溃重载 |

这个系统不指导玩家，它只是让玩家感受到：**有人在等他们。有人知道他们在靠近。**

# 第三章：游戏入口设计

---

## 3.1 游戏启动画面

游戏启动，没有标题画面，没有菜单，没有任何"游戏感"的界面。

直接呈现：**一台电脑的桌面，已经有三个窗口是打开的。**

玩家看到的，是一个已经发生了很多事情的现场中段。

**窗口一：微信网页版**

对话列表排在第一位的是"林晓"，头像旁边有一个红色数字：3（未读）。

打开对话，从下往上：

## 3.3 入口触发点

玩家在桌面上能做的事：

**点击邮件里的链接**（`tranquil-sleep.com`）→ 进入官网，游戏正式开始

**尝试回复林晓的微信** → 输入框可以打字，发送后显示"消息发送失败，对方可能已关闭消息通知"（系统提示，非剧情）

**点击照片放大查看** → 照片可以放大，没有额外信息，但让玩家花时间和林晓在一起

**什么都不做** → 桌面保持静止，没有任何提示，没有任何指引。等。

第一个设计原则在这里生效：**游戏不告诉玩家该做什么。玩家只是跟着一个凌晨睡不着的哥哥，点开了那个链接。**

# 第四章：官网——第一信息层

---

## 4.1 官网的整体设计原则

官网必须看起来像一家真实存在的高端医疗机构的官网。

极简冷蓝与原白配色。字体是无衬线体，行距宽松。没有任何闪烁的广告，没有任何刺激性的视觉元素。整个网站的视觉语言在说：**我们是专业的，我们是克制的，我们值得信任。**

官网的裂缝，不是通过视觉异常展示的（除了林晓的信号），而是通过**措辞的精确到奇怪**，通过**信息的空缺**，通过**时间线的矛盾**展示的。

## 4.2 官网完整内容清单

### 主页

标语："重建深层睡眠的神经秩序"

三个数字：12,000+（服务患者数）、93%（有效改善率）、4.8/5（患者满意度）

这三个数字全部真实——12,000+是历史总服务患者数，包含那些被"处理"的；93%有效改善率来自真实的20%正常治疗患者的康复数据，分母只计算了"完成疗程并反馈"的患者；4.8分来自官方筛选过的评价。

没有一个数字是假的。每一个数字都是谎言。

主页底部有一行极小的版权声明：
`© 2019-2024 安宁深眠（南郊）医疗研究中心 保留所有权利`

---

### 关于我们

诊所的创立历程，写得极为精心。创始人介绍，发展历程，国际合作，荣誉资质。

**关键细节（裂缝）：**

> "2009年，钟院长凭借其在麻省理工学院的开创性睡眠神经科学研究，奠定了DNR疗法的理论基础。"

2009年钟长明的论文是关于"海马体突触可塑性"的，与DNR疗法没有直接关联。他在MIT真正研究过的那个方向，有一篇撤稿记录。

玩家在此处感知到的只是"这段话感觉有点对不上"，不会立刻知道为什么。这是一个播下的种子。

### 专家团队

**钟长明的页面：**

照片、履历、一段本人感言。

感言最后一句：

> "我深知长期失眠患者的痛苦，因为我自己也曾是其中一员。那段经历让我明白：修复一个人的睡眠，就是修复一个人的生命本身。"

这句话是真实的。他在2006年论文被否后确实有过两年严重失眠。

感言旁边有一个小按钮："查看学术成果"→ 跳转到一个伪造的学术数据库页面。

**学术数据库页面（关键线索节点）：**

列出钟长明的所有发表论文，包括2009年的高引用率论文。

但在2006年那个位置，有一条撤稿记录，灰色显示：

```
[已撤稿] 钟长明 (2006)
《灵子场：意识的非局域性量子信息基底》
撤稿原因：实验设计不符合可证伪性标准
原发表期刊：[投稿中，未发表]
```

这是玩家第一次看到"灵子"这个词。

→ **触发RUNE_02备用路径**：如果玩家已经看过源码里的赵启注释，这条撤稿记录会让他们把两件事联系起来。

**林医生的页面：**

正常的医生介绍。四篇专栏文章链接。

介绍最后一行："本院神经内科主任，钟院长的学术继承人。"

---

### DNR疗法介绍

这是整个官网信息密度最高的页面，也是裂缝最多的页面。

页面分三个部分：

**第一部分：什么是DNR**

> "深度神经共振疗法（Deep Neural Resonance，DNR）是本院独家研发的第三代睡眠重建系统。通过精密的低频电磁波序列，作用于大脑海马体与丘脑之间的特定神经元突触群，在五分钟内为您的神经系统提供毫无杂念的深眠窗口。"

**"毫无杂念"**——没有任何正规医疗机构会用这个词描述医疗过程。

**第二部分：疗程说明**

> "每次疗程约为45分钟，建议连续进行14天以获得最佳效果。治疗期间患者将在专用DNR舱内接受治疗，过程中可能出现轻微的感知模糊，属正常反应。"

**"感知模糊"**——专业医疗文件里，这个词应该被替换成具体的神经学描述。"感知模糊"是一种模糊的表达，专业机构不会这样写。

**第三部分：DNR舱体介绍**

一张白色流线型舱体的设计图。

### 岔路二：玩家找到密码TaiYiJiuKu但跳过了大量内容

玩家理论上可以通过：阅读林医生文章四→查看OA机柜照片→合并密码，在跳过大量内容的情况下得到最终密码。

系统响应：允许。这是一个极端路径，玩家会进入终局，但只有极少数碎片，只能看到A和B结局，且对整个世界的理解极为片面。

这是允许的，因为它不破坏游戏的核心体验——玩家选择了用最快的方式到达终点，他们得到的结局质量对应他们投入的深度。

### 岔路三：玩家在终局界面选择先回去补碎片

允许。终局界面有一个"返回调查"按钮，玩家可以返回，游戏状态完整保存。

### 岔路四：玩家重复游玩（第二次进入游戏）

游戏使用本地存储记录进度，但提供一个"重新开始"选项。重新开始后，所有状态清零，游戏从桌面重新开始。

这为玩家第二次游玩、探索不同结局提供了机制支持。

### 岔路五：玩家在某个步骤卡住，什么都找不到

这是最重要的岔路。

游戏不提供任何明示提示，但有一套**被动的环境暗示系统**：

- 如果玩家在官网停留超过10分钟没有任何新进展，林晓的信号强度+1（即使此时碎片为0），触发一次更明显的溢出信号
- 如果玩家在论坛停留超过8分钟没有新进展，搜索框轻微发光一次（暗示"这里可以搜索"）
- 如果玩家已经登录OA但没有找到B2报告，系统在模块四旁边显示一个`[!]`标记

以上全部是极为克制的提示，不破坏沉浸感，只在玩家真的卡住时提供最低限度的方向暗示。

# 第十二章：必须遵守的设计红线

---

## 12.1 绝对不允许的设计

1. **任何形式的直接指引文字**——"去某某地方找某某东西"的句式，无论以何种形式出现，都是禁止的
2. **任何元游戏语言出现在游戏内**——"解锁XX"、"收集XX"、"完成XX任务"，这些词汇不存在于这个世界里
3. **信息平白呈现而不是让玩家挖掘**——任何重要信息，必须以一种需要玩家主动发现的形式存在
4. **结局被美化**——三个结局都不是干净的，都不允许被处理成"胜利画面"

## 12.2 世界观底层因果律（锁死，不可改动）

- 太岁高维图灵机本质
- 灵子信息流理论
- DNR物理剥壳算法（以及它的名字本身是"数字招魂程序"的缩写）
- 南郊阴脉地磁屏蔽（历史原因+物理特性）
- 10PM重金属致幻药物
- 寡头超维预测机与黄粱道数字飞升双线动机
- 赵启七碎片反制程序
- 林晓零号异常节点体质与溢出信号机制
- 临界加速机制（太岁已在从另一侧推门）

## 12.3 情感优先于机制

任何时候机制设计与情感设计发生冲突，优先保证情感体验。

具体来说：如果某个机制上正确的设计（比如"防穿越检查"）会破坏玩家在某个特定时刻的沉浸感，那就调整机制，不要调整情感节奏。
