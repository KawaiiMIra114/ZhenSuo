# 《镇锁》Art & UI Request List v1
## UI 组件与美术资产需求总表

> **文档职责**
> 本文档是美术、UI 设计与前端开发的“视觉施工图”。
> 它将《镇锁》中的五大信息层（现实桌面、诊所官网、患者论坛、内部 OA/影子档案层、终局层）转化为具体的 UI 组件与图像资产需求。
> **核心美学原则**：临床的冰冷感、官僚的折叠感、工程的深渊感，以及被暴力撕裂的系统截断感。

---

### 一、 全局核心 UI 组件 (Global Core UI)

整部游戏中，唯一贯穿始终的 UI 元素就是“统一搜索框”。它的视觉状态必须随着玩家下潜的深度发生异化。

| 资产 ID | 资产名称 / 类型 | 视觉与交互需求描述 | 优先级 |
| :--- | :--- | :--- | :--- |
| **UI-GLB-01** | 全局统一搜索框 | **形态**：极简、居中或悬浮，不带任何多余的“搜索按钮”图标，依靠 Enter 触发。<br>**状态异化**：<br>- 官网层：现代、圆角、符合医疗机构的洁净感。<br>- 论坛层：略显陈旧的社区搜索框。<br>- 内部层：变成无边框的终端命令行输入条（如 `> _` 闪烁光标）。 | P0 |
| **UI-GLB-02** | 查询不足/系统拦截反馈弹窗 | **形态**：不能做成花哨的“错误对话框”。<br>**视觉**：类似网页底层的 Toast 提示，或直接在页面顶部下拉的纯文本警告框。颜色偏向工程警告（灰红或灰黄），而非消费级 APP 的弹窗。 | P0 |
| **UI-GLB-03** | 全局统一终端字体集 | 采购或设定一套专门用于内部层（OA、影子档案、终局）的等宽字体（Monospace）。必须具备强烈的代码感和无机质感。 | P0 |

---

### 二、 现实物料与初始层 (Desktop & Reality Layer)

这一层的视觉目标是“极度真实”，让玩家确信林晓是一个活生生的、在现实中失联的人。

| 资产 ID | 资产名称 / 类型 | 视觉与交互需求描述 | 优先级 |
| :--- | :--- | :--- | :--- |
| **ART-DSK-01** | 门诊单扫描件 (`DSK-CLM-01`) | **形态**：一张被揉皱后又展平、带有扫描仪强曝光特征的 A4 纸图像。<br>**关键细节**：<br>- 顶部的“安宁深眠诊所” Logo（需要有医疗/科技结合的虚伪高级感）。<br>- 医生“林德坤”的潦草手写签名与红色印章。<br>- **最重要**：右下角用截然不同的黑色圆珠笔，极其用力地写下的一串字：`LX-044-YIN`。 | P0 |
| **ART-DSK-02** | 照片：林晓最后的消息 | **形态**：一张极其日常视角的手机随手拍（如模糊的医院走廊、窗外的特定标志物），带有微信/短信等聊天软件界面的截图外壳。 | P1 |

### 三、 安宁深眠官网层 (Clinic Website Layer)

视觉目标：“伪善的高端”。表面上是一个充满人文关怀、极度专业的现代医疗/脑科学机构。

| 资产 ID | 资产名称 / 类型 | 视觉与交互需求描述 | 优先级 |
| :--- | :--- | :--- | :--- |
| **UI-WEB-01** | 官网母版 UI | **配色**：以医疗蓝、纯白、银灰为主。排版极其开阔、呼吸感强。<br>**组件**：导航栏（专家团队、DNR 疗程、新闻动态）、页脚（极小的 Meridian Life Sciences 资本标识）。 | P0 |
| **UI-WEB-02** | 患者评价卡片流 | **形态**：标准的瀑布流或轮播卡片。带有虚假的“五星评分”UI。`gh_0314_lx` 的那条评价卡片在视觉上应与其他完美评价产生微妙的不谐感（排版略微错位或颜色微暗）。 | P1 |
| **UI-WEB-03** | 异常命中页模版 (`CL-ARCH-RSP`) | **视觉突变**：当玩家搜出异常编号时，瞬间破坏官网的洁净感。白底突变黑底，或出现红色的系统底层报错文本（参考 Kernel Panic 界面）。 | P0 |

---

### 四、 患者论坛层 (Forum Layer)

视觉目标：“带有人味的陈旧”。介于早期的病友贴吧与现代医疗问答社区之间。

| 资产 ID | 资产名称 / 类型 | 视觉与交互需求描述 | 优先级 |
| :--- | :--- | :--- | :--- |
| **UI-FR-01** | 论坛母版 UI | **配色**：褪色的冷色调。排版密集，带有发帖时间、浏览量、发帖人 ID 等标准 BBS 字段。<br>**组件**：高亮的“家属互助区”置顶标识。 | P0 |
| **UI-FR-02** | 自动化折叠 / 删除警告框 | **形态**：极度冰冷的机器官僚主义。<br>**文案视觉**：“该讨论已被系统依据《社区规范》自动化归档”。配色使用极具压迫感的深灰背景+白字，取代原本帖子的位置。 | P0 |

---

### 五、 内部 OA 与影子档案层 (OA & Shadow Archive Layer)

视觉目标：“深渊与证据”。彻底抛弃前端的装饰，暴露系统的工程本质。

| 资产 ID | 资产名称 / 类型 | 视觉与交互需求描述 | 优先级 |
| :--- | :--- | :--- | :--- |
| **UI-OA-01** | 纯净数据表盘 (B2 负载报告等) | **形态**：无设计感的数据报表。大量由等宽字体排列的表格、监控时间戳、状态指示灯（如常亮的红点代表节点超载）。 | P1 |
| **UI-SA-01** | 证据包容器 (Evidence Packet) | **严格按照指南设计**：<br>- 顶部带有抓取乱码和时间戳（Capture Metadata）。<br>- 中间是由 `[系统覆写前]` 和 `[原字段]` 组成的高对比度差异文本。<br>- 底部带有手写体或注释高亮背景的“赵启残注”。<br>- 边缘带有视觉上的“撕裂”或“加载不全的雪花干扰”。 | P0 |
| **ART-OA-01** | B2 节点示意图 (`OA-IMG-01`) | **形态**：一张极其反人类直觉的工程拓扑图。<br>**内容**：将七个物理服务器节点以某种类似于“北斗七星”或“某种封印阵法”的物理走线方式连接起来，但必须画成标准的 CAD 蓝图或网络拓扑图，用科学的外衣包装玄学/残忍的内核。 | P2 |

---

### 六、 终局执行层 (Terminal Layer)

视觉目标：“代价的容器”。极简、压抑、不可逆。

| 资产 ID | 资产名称 / 类型 | 视觉与交互需求描述 | 优先级 |
| :--- | :--- | :--- | :--- |
| **UI-TM-01** | 执行确认界 | **形态**：整个屏幕只有一个冷酷的居中输入框和几行简短的执行代价说明。没有任何多余的色彩，只有黑与白，或极其刺眼的警告色。 | P0 |
| **ART-TM-01** | 三结局视觉反馈 (余波) | - **结局 A (烈火洗城)**：屏幕边缘出现烧焦的碳化材质特效，文字逐渐被灰烬覆盖。<br>- **结局 B (上行替代)**：类似代码被吞噬、重组的数字溶解特效，UI 变得极其平滑、顺从。<br>- **结局 C (七星破阵)**：屏幕上 7 个指示灯依次熄灭，最后陷入彻底的纯黑界面，只留下终端光标闪烁。 | P1 |

---

> **执行建议**
> 美术与 UI 团队优先产出 **P0 级别** 的资产：全局搜索框、异常拦截弹窗、门诊单扫描件、官网母版、论坛母版、证据包容器。
> 这 6 项资产齐备后，研发团队的 PoC（技术切片）即可直接套壳，并具备完整的游戏氛围体验。
