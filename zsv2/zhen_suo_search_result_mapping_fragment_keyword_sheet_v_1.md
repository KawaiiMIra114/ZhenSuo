# 《镇锁》Search Result Mapping & Fragment Keyword Sheet v1

> **文档职责**
> 本文档是《镇锁》检索系统的"神经接线图"。它将 RTB Bible 中的"关键词触发网络"落实为具体的映射关系。
> 研发团队与文案团队必须依据此表来配置触发条件与文案出口。
> **内部限定**：本表仅用于内部配置，不可直接外露到客户端、公开文案或对外配置说明。
> 本表重点覆盖 Batch 1（官网层）、Batch 2（论坛层）及部分 Batch 3（管理/OA 边缘）的核心映射。

### 三、 查询不足与防爆破反馈 (Insufficient Query Fallbacks)

当玩家试图用"裸词"去爆破深层系统，或者输入了尚未解锁语境的词汇时，系统**禁止**返回"权限不足（Permission Denied）"，必须按以下逻辑返回。

| 玩家行为 | 系统底层判定 | 返回模板类型 | 呈现文案示例 |
| :--- | :--- | :--- | :--- |
| 直接搜索 `OA` 或 `内部系统` | 裸词查询深层 | **查询不足 / 目录投影** | "当前检索范围过宽，仅返回公开设施目录。请补充具体模块名或执行语境。" |
| 提前搜索 `TaiYiJiuKu` (碎片未齐) | 条件未闭合 | **结构未闭合** | "节点响应不足，当前结构无法承载该执行指令。缺少必要的前置校验。" |
| 搜索无效但相关的乱码 | 无效触发词 | **查询不足 (0结果)** | "当前索引范围内未形成稳定命中。请核对检索词准确性。" |
| 搜索涉及其他病患真实姓名 | 无效对象 | **受限投影 / 0结果** | "基于隐私保护规则，该对象未在公开域建立索引。" |
